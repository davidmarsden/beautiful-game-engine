# The Beautiful Game — Engine

A deliberately small first engine scaffold.

Current target:

> Generate a deterministic 100-club, five-division world shell.

No UI. No transfers. No youth. No finance. No real match engine yet.

## Commands

```bash
npm test
npm run demo
```

## First milestone

- 100 clubs
- 5 divisions
- 20 clubs per division
- deterministic generation from seed
- stable IDs
- basic club strength bands
- season shell fixture counts
